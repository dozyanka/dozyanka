## 🚀 Основной проект

### [PM Assistant](https://github.com/dozyanka/pm-assistant)

Self-hosted AI-ассистент для проектных менеджеров, который превращает разрозненные проектные коммуникации в проверяемую память проекта.

**Возможности:**

- ответы на вопросы по проекту с привязкой к исходным сообщениям;
- реестр задач, решений, обещаний, требований и зависимостей;
- Kanban-таск-трекер;
- генерация Post-meeting;
- определение и ручная проверка ролей участников;
- импорт DOCX / JSON / JSONL / TXT;
- семантический поиск через embeddings;
- локальный inference LLM через Ollama;
- Windows Desktop;
- отдельный Remote Server + Windows Client;
- CI-тесты через GitHub Actions.

**Стек:**  
`Python` `JavaScript` `HTML/CSS` `SQLite` `Ollama` `Qwen` `RAG` `Embeddings` `REST API` `PyInstaller` `Tailscale`
